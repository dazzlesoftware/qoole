Data for the Genesis Editor (GenesisEditor.exe):

  ents/genesis.ent   entity definitions of the built-in "Genesis" game
  gems/*.gem         entity wireframes (the crosshair and undefined-entity
                     markers every entity set needs, a light and a player)
  brushes/*.qle      prefab brushes for the Prefabs panel

The gems and prefab brushes come from the data file of Qoole 99 (released
under the GNU GPL with its source). Prefabs you save from the editor go to
%LOCALAPPDATA%\Genesis\Editor\Prefabs.
